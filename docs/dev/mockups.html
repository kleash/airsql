Themes

Porcelain and Deep Water

Both are built from macOS system colours, the way AirSCP's are, so they follow the user's accent colour, Increase Contrast and Reduce Transparency without a theme setting. AirSQL adds a petrol-blue tint, colours chosen for data (value types, pending edits, SQL highlighting) and connection colours that tint the toolbar edge and active tab. Light: a cool grey window ground with white content and a near-black selected pill. Dark: blue-black surfaces with a 6% petrol wash, so long sessions are easy on the eyes and the accent stays readable.

Plan

How 1.0 gets built

The full plan is plan.md. Version 2, after an adversarial review that changed the tunnels (private Unix sockets), TLS checks, the agent gate (fails closed), Apply checks and the lane order. Every lane runs as one batch: implement, verify in one pass, adversarial review, then integration by the orchestrating session. Speed comes from parallel lanes that own separate files, not from skipping checks.

Each lane, one pass

ImplementOne agent per lane in its own worktree and branch. All its scope rows as one batch, with tests and docs.
VerifyZero-warning build, unit tests, lab tests for the lane, app driven through each new flow with light and dark screenshots.
Review per waveThree reviewers over the whole wave: security and data safety, UI/UX polish, correctness and simplicity. Fixes in one batch, re-checked once.
IntegrateThe orchestrator rebases, runs everything, looks at the screenshots, rejects anything over-engineered, opens the pull request, waits for CI, merges.

Quality gates that never bend

AreaGate
CodeSwift 5 mode, zero warnings, no third-party Swift packages, smallest change that solves the row, AirSCP patterns
SecuritySecrets only in the Keychain; all SQL through quoting helpers with hostile-input tests; LOCAL INFILE off; TLS verification by default; agents read-only with ask-first for writes; relays on 127.0.0.1 only
UIEvery control and menu item has a tooltip (tested); right-click, double-click, multi-select and shortcuts everywhere; light and dark checked by screenshot
UXPlain words, empty states that say what to do, errors that say how to fix them, nothing written without Apply or Run
SpeedGrid at 1 M rows and 300 columns at 120 Hz; launch under 1 s; idle memory under 150 MB; performance tests fail the build
Data safetyGrid edits in one transaction, keyed by primary or NOT NULL unique key; production previews and confirmations; recon and restore never run without review
